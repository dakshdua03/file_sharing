## Emerging Technologies Used in These Papers

These papers show the direction current research is taking:

| Technology | Purpose |
| --- | --- |
| Searchable Encryption (SE) | Search encrypted files without decrypting them |
| Attribute-Based Encryption (ABE) | Fine-grained access control |
| Proxy Re-encryption (PRE) | Securely share files without revealing encryption keys |
| Blockchain | Immutable access logs and tamper-proof auditing |
| IPFS | Decentralized file storage |
| Homomorphic Encryption | Operate on encrypted data |
| Zero-Knowledge Proofs | Verify actions without revealing secrets |
| Post-Quantum Cryptography | Protect against future quantum attacks |
| Secret Sharing | Split encryption keys among multiple parties |
