**Here are recent research papers (primarily 2024–2026) on breakthroughs and advancements in secured file sharing systems.** These cover themes such as end-to-end encryption enhancements, blockchain/IPFS integration for auditability and decentralization, zero-knowledge proofs, threshold secret sharing, semantic search over encrypted data, dynamic/neural key generation, attribute-based encryption, and post-compromise security.

I prioritized peer-reviewed or arXiv papers with clear technical contributions over commercial product reviews or surveys alone. Links point to publisher pages, arXiv PDFs, or institutional hosts where available (some may require institutional access).

### Encryption, Anonymity & Cryptographic Foundations

-   **Beyond Nonce Uniqueness: A Cryptographic Evaluation of AES-GCM in Secure Anonymous File Sharing Systems** (ICDSA 2025 / Springer LNNS, first online Feb 2026). Evaluates AES-256-GCM in a serverless FastAPI + AWS S3 anonymous sharing system with client-side encryption, unique IVs, optional Argon2id password protection, and performance benchmarks vs. AES-CCM/ChaCha20-Poly1305. Includes deployment guidelines and notes on post-quantum/zero-knowledge extensions. URL: [https://link.springer.com/chapter/10.1007/978-3-032-15407-1\_26](https://link.springer.com/chapter/10.1007/978-3-032-15407-1_26)[⁠Link.springer](https://link.springer.com/chapter/10.1007/978-3-032-15407-1_26)
-   **Neural-driven dynamic key generation: A deep reinforcement learning and topological mathematics based framework for secure file sharing** (_Results in Control and Optimization_, Vol. 24, Sept 2026). Integrates deep reinforcement learning for a CSPRNG generating dynamic session keys + algebraic knot theory (topological transformations) for resilience against key recovery. Validated via entropy, randomness, Hamming distance, and runtime tests; aims to overcome static-key vulnerabilities. Open access. URL: [https://www.sciencedirect.com/science/article/pii/S2666720726000925](https://www.sciencedirect.com/science/article/pii/S2666720726000925)[⁠ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2666720726000925)
-   **Securing End-To-End Encrypted File Sharing Services With the Messaging Layer Security Protocol** (_Concurrency and Computation: Practice and Experience_, 2025). Architecture combining MLS group key exchange, attribute-based access control, and a tamper-resistant versioned metadata store for post-compromise security (and limited forward secrecy). Includes prototype, security analysis against common threats, and key-distribution scalability benchmarks (e.g., 10k keys to 1k clients). URL: [https://onlinelibrary.wiley.com/doi/10.1002/cpe.70414](https://onlinelibrary.wiley.com/doi/10.1002/cpe.70414)[⁠Onlinelibrary.wiley](https://onlinelibrary.wiley.com/doi/10.1002/cpe.70414)

### Blockchain, Decentralized & Auditable Systems

-   **FileDES: A Secure, Scalable and Succinct Decentralized Encrypted Storage Network** (IEEE INFOCOM 2024; arXiv:2403.14985). Decentralized encrypted storage with privacy preservation (RSA + unidirectional proxy re-encryption), scalable Proof of Encrypted Storage (PoES) resistant to Sybil/Generation attacks, and rollup-based batch verification with succinct publicly verifiable proofs. Outperforms Filecoin/Storj/Sia on proof efficiency, storage cost, and scalability (tested up to 120 nodes). arXiv PDF: [https://arxiv.org/pdf/2403.14985](https://arxiv.org/pdf/2403.14985) abs: [https://arxiv.org/abs/2403.14985](https://arxiv.org/abs/2403.14985)[⁠arXiv](https://arxiv.org/pdf/2403.14985)
-   **SecureChainFS: A Blockchain-Augmented File Transfer System with Tamper-Evident Audit Trails** (2026 International Conference on Emerging Technologies and Future Innovations). Client-side E2EE + IPFS storage; batches file operations into Merkle trees recorded on Hyperledger Fabric for immutable audit trails. Claims ~94% lower logging overhead, high throughput (~847 files/min in 30s batches), and high accuracy detecting unauthorized tampering. URL: [https://ieeexplore.ieee.org/abstract/document/11484826/](https://ieeexplore.ieee.org/abstract/document/11484826/)[⁠Ieeexplore.ieee](https://ieeexplore.ieee.org/abstract/document/11484826/)
-   **Auditable cross-domain data sharing via threshold secret sharing and zero-knowledge proofs** (_Journal of Information Security and Applications_, Vol. 100, July 2026). Blockchain scheme that decentralizes encrypted file fragments and key shares via threshold cryptography (no single entity can reconstruct keys or transform ciphertexts unilaterally). Non-interactive ZK proofs enable public verification of operations without revealing plaintext/keys/metadata; blockchain provides tamper-evident audit. Security analysis + experimental overhead evaluation. URL: [https://www.sciencedirect.com/science/article/abs/pii/S2214212626001274](https://www.sciencedirect.com/science/article/abs/pii/S2214212626001274)[⁠ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S2214212626001274)

### Semantic Search, Hierarchical Control & Advanced Access

-   **Constellation: Semantic Search over Encrypted Shared Files** (Berkeley project report / course paper, ~2025). File-sharing system achieving access-pattern hiding (via two non-colluding servers + ORAM), high concurrency, and semantic search over encrypted data. Decouples low-latency client ops from background maintenance; leverages embedding stability for relaxed consistency (low accuracy degradation). PDF: [https://people.eecs.berkeley.edu/~kubitron/courses/cs262a-F25/projects/reports/project1006\_paper\_85262889807149618246.pdf](https://people.eecs.berkeley.edu/~kubitron/courses/cs262a-F25/projects/reports/project1006_paper_85262889807149618246.pdf)[⁠People.eecs.berkeley](https://people.eecs.berkeley.edu/~kubitron/courses/cs262a-F25/projects/reports/project1006_paper_85262889807149618246.pdf)
-   **PODS: Efficient and Secure Identity-Based Hierarchical Data Processing Control in Mobile Cloud Storage** (Beijing Institute of Technology, ~2026). Identity-based hierarchical control for multi-user mobile cloud storage enabling equality/comparison/plaintext analytics with a single ciphertext for multiple users. Reconstructs identity-based encryption, encodes identities as polynomial coefficients for privacy and efficiency (~8× computation / 37× communication improvement claimed). URL: [https://pure.bit.edu.cn/en/publications/pods-efficient-and-secure-identity-based-hierarchical-data-proces/](https://pure.bit.edu.cn/en/publications/pods-efficient-and-secure-identity-based-hierarchical-data-proces/)[⁠Pure.bit](https://pure.bit.edu.cn/en/publications/pods-efficient-and-secure-identity-based-hierarchical-data-proces/)
-   **A Lightweight and Efficient Elliptic Curve Cryptography Based File Hierarchy Attribute-Based Encryption Scheme with Enhanced Security and Cross-Domain Data Sharing** (_Electronics_, MDPI, 2026). ECC-based hierarchical CP-ABE replacing bilinear pairings with scalar multiplications for IoT/resource-constrained settings. Adds random noise against collusion, supports cross-domain batch access; formal IND-CPA proof under ECDDH; large reductions in computation/communication vs. prior schemes. URL: [https://www.mdpi.com/2079-9292/15/4/762](https://www.mdpi.com/2079-9292/15/4/762)[⁠Mdpi](https://www.mdpi.com/2079-9292/15/4/762)
