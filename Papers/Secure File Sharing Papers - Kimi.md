Here is a curated collection of recent research papers on breakthroughs and technology advancements in secured file sharing systems, organized by key technological themes:

___

## 🔐 Multi-Factor Authentication & Access Control

**1\. Secure File Sharing System with Strong Password and One Time Password Authentication**

-   **Authors:** Chee Lee Chong, Nur Ziadah Harun
    
-   **Published:** 2025, _Journal of Computing Research and Innovation_
    
-   **Focus:** Multi-factor authentication (MFA), end-to-end encryption, hashing, and secure session management for file sharing.
    

___

## ⛓️ Blockchain & Decentralized File Sharing

**2\. An Efficient Blockchain-Based Framework for File Sharing**

-   **Published:** August 2024, _Nature Scientific Reports_ (Authority: S)
    
-   **Focus:** Blockchain-based P2P file sharing, IPFS integration, DAG distributed ledgers, and decentralized storage overcoming C/S model limitations.
    

**3\. Block Share: A Blockchain-Based File Storage and Sharing System Using IPFS**

-   **Authors:** M. Shiva Kumar, Shashank Bhake, et al.
    
-   **Published:** 2025, _Proceedings of ICCSCE 2025_
    
-   **Focus:** Ethereum smart contracts, Zero Trust model, end-to-end encryption, MetaMask wallet integration, and IPFS decentralized storage.
    

**4\. Secure File Sharing Using Blockchain and IPFS with Smart Contract-Based Access Control**

-   **Published:** March 2025
    
-   **Focus:** AES-256 encryption, SHA-256 hashing, smart contract-based dynamic access control, and PoS/PoA consensus mechanisms.
    

**5\. Peer-to-Peer File Sharing System Using Blockchain**

-   **Published:** _AIP Conference Proceedings_
    
-   **Focus:** Blockchain-enhanced P2P file sharing systems.
    

**6\. Blockchain-Based Inter-Organization File Sharing System**

-   **Author:** Durga Venkata Suraj Tedla
    
-   **Published:** May 2024, University of Kansas
    
-   **Focus:** Hyperledger Fabric, IPFS, smart contracts for secure inter-organizational file sharing with availability, integrity, and confidentiality.
    

**7\. Blockchain-Based File Sharing System – A Hybrid Approach**

-   **Published:** July 2024
    
-   **Focus:** Hybrid blockchain-IPFS approach for secure and efficient data sharing.
    

___

## ☁️ Cloud & Big Data Security

**8\. Secure File Sharing System Using Big Data in the Cloud**

-   **Author:** A.K. Singh
    
-   **Published:** 2023/2026, _IEEE_ (Authority: S)
    
-   **Focus:** Big data security categorization (structured, semi-structured, unstructured) in cloud environments.
    

___

## 🔑 Attribute-Based Encryption (ABE)

**9\. A Systematic Review of Attribute-Based Encryption for Secure Data Sharing**

-   **Published:** February 2024
    
-   **Focus:** Comprehensive review of CP-ABE, KP-ABE, proxy re-encryption, and revocation mechanisms for secure cloud/IoT data sharing.
    

**10\. Overview and Considerations of Access Control Based on Attribute-Based Encryption**

-   **Published:** 2023, _NIST IR 8450_ (Authority: S)
    
-   **Focus:** NIST guidelines on ABE for cryptographically-enforced selective access control.
    

___

## 🏛️ Standards & Guidelines

**11\. Security Considerations for Exchanging Files Over the Internet**

-   **Authors:** Karen Scarfone, Matthew Scholl, Murugiah Souppaya
    
-   **Published:** 2020/2021, _NIST ITL Bulletin_ (Authority: S)
    
-   **Focus:** NIST recommendations for secure file exchanges, encryption, and telework security.
