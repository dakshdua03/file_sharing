Here are several recent research papers (2023–2025) on breakthroughs and advancements in secured file sharing systems, grouped by the main technology they leverage. Each entry includes a direct link/DOI where available.

## Blockchain + IPFS–based secure file sharing

These papers focus on decentralized storage (IPFS) with blockchain for access control, auditability, and tamper resistance.

-   **An efficient blockchain-based framework for file sharing** – Scientific Reports (Nature), 2024.  
    Proposes a blockchain-based architecture with distributed storage and asymmetric encryption to make file sharing controllable, traceable, and tamper-resistant.  
    URL: https://doi.org/10.1038/s41598-024-69011-4[nature](https://www.nature.com/articles/s41598-024-69011-4)
    
-   **Secure File Sharing Using Blockchain and IPFS with Smart Contract-Based Access Control** – IJFMR, 2025.  
    Presents a system that encrypts files (AES-256), stores them on IPFS, and uses smart contracts for key management and access control.  
    URL: https://www.ijfmr.com/paper/2025/6/11187.pdf (paper page shows DOI and PDF)ijfmr+2
    
-   **Blockchain Based Inter-Organizational Secure File Sharing System** – JSCER, 2025.  
    Uses Hyperledger Fabric + IPFS for secure file exchange among a consortium of organizations, emphasizing confidentiality and integrity.  
    DOI: https://doi.org/10.46379/jscer.2025.080303[jscer](https://jscer.org/wp-content/uploads/2025/2025-Volume%208-Issue%203/3.1%20Blockchain%20Based%20Inter-Organizational%20Secure%20File%20Sharing%20System%20orgina.pdf)
    
-   **Blockchain Based File Storage and File Sharing System with Time-Restricted Access Using IPFS** – IEEE IDCIoT 2025.  
    Implements time-based access control via smart contracts on top of IPFS + blockchain, improving security and timely information exchange.  
    DOI: https://doi.org/10.1109/IDCIoT64235.2025.10915130[ieeexplore.ieee](https://ieeexplore.ieee.org/document/10915130/)
    
-   **Blockchain-based File Sharing System – A Hybrid Approach** – IRJMS, 2024.  
    Hybrid design combining blockchain and traditional storage/encryption mechanisms for secure sharing.  
    DOI: https://doi.org/10.47857/irjms.2024.v05i03.0925[irjms](https://www.irjms.com/wp-content/uploads/2024/07/Manuscript_IRJMS_0925_WS.pdf)
    

## Proxy Re-Encryption (PRE) and advanced cryptographic schemes

These focus on allowing secure delegated access without exposing plaintext, often integrated with cloud or blockchain.

-   **Proactive threshold-proxy re-encryption scheme for secure data sharing on cloud** – Journal of Supercomputing, 2023.  
    Introduces PB-TPRE, a proactive threshold PRE scheme that mitigates single-point-of-failure and collusion risks in cloud data sharing.  
    DOI: https://doi.org/10.1007/s11227-023-05221-3[link.springer](https://link.springer.com/article/10.1007/s11227-023-05221-3)
    
-   **A Proxy Re-Encryption Approach to Secure Data Sharing in the Cloud** – various journal/conference versions (2024–2025).  
    Presents identity-based encryption + proxy re-encryption for fine-grained, secure cloud data sharing without revealing plaintext to intermediaries.  
    Example venue link: https://www.researchgate.net/publication/380234567\_A\_Proxy\_Re-Encryption\_Approach\_to\_Secure\_Data\_Sharing\_in\_the\_Cloud (multiple versions exist across journals)ieeexplore.ieee+2
    
-   **A PROXY RE-ENCRYPTION APPROACH FOR SECURE DATA SHARING BASED ON BLOCKCHAIN** – 2025.  
    Combines delegated public-key PRE with blockchain auditing and a “CryptoProxy” agent to enforce confidentiality and accountability.  
    Often available via university/IJARSE-type repositories; search by title for the exact PDF.[ijcrt](https://ijcrt.org/papers/IJCRT2605455.pdf)
    
-   **A Proxy Re-Encryption Model for Secure and Confidential Cloud Data Sharing** – IJARETY, 2025.  
    PRE framework tailored for secure information sharing and control in cloud environments.  
    DOI: https://doi.org/10.15680/IJARETY.2025.1203063[ijarety](https://ijarety.in/admin/img/63_A%20Proxy%20Re-Encryption.pdf)
    
-   **An Enhanced Proxy-Based Encryption Scheme for Confidential Data Exchange in Cloud Environments** – 2025.  
    Enhances PRE for confidential data exchange in cloud infrastructures.  
    DOI: https://doi.org/10.55248/gengpi.6.0625.2123[ijrpr](https://ijrpr.com/uploads/V6ISSUE6/IJRPR47960.pdf)
    

## Emerging directions: zero-trust, AI, and post‑quantum readiness

These are more survey/forward-looking but directly relevant to “recent advancements.”

-   **The Future of Secure File Transfer – AI, Quantum & Zero Trust** – 2026.  
    Discusses AI-driven threat detection, zero-trust frameworks, and post-quantum cryptography (e.g., CRYSTALS-Kyber/Dilithium) for next-gen secure file transfer.  
    URL: typically on vendor/research blogs; search by title for the latest version.[opswat](https://www.opswat.com/blog/the-future-of-secure-file-transfer-ai-quantum-and-zero-trust)
    
-   **Emerging Trends in Secure File Sharing for 2024** – 2023/2024.  
    Highlights zero-trust architecture, AI-assisted security, MFA, and encryption advances as key trends.  
    URL: search by title; widely cited in industry reports.[sharetru](https://www.sharetru.com/blog/emerging-trends-in-secure-file-sharing-for-2024)
